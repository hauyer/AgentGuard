# AgentGuard 接口决策记录（0.1）

## 决策 1：契约与实现分离
核心协议位于 `contracts/`；底层仓库的对象只在 adapter 内转换，不允许业务模块直接依赖底层私有类。

## 决策 2：真值隔离
场景和运行时 Observation 不应包含中央评价器的隐藏真值。真值只由独立 Evaluator 读取。API 不提供 truth 字段。

## 决策 3：能力显式声明
不支持的干预返回 `unsupported`，不能把黑盒模型伪装成 activation-capable 白盒模型。

## 决策 4：合成结果显式标记
Mock 后端的检测、干预和指标一律是 synthetic/simulated。不能用于论文实证结论或比赛性能数字。

## 决策 5：证据不等于结论
运行轨迹属于观测证据；单次干预属于干预证据。`causal_validated` 只允许在外部严格实验审查后由受信任流程赋予，MVP 不会自动赋予。

## 决策 6：适配器先于深度集成
FRACTAL-Bench / StegoPot 的真实接入必须绑定固定提交版本，并为转换后的每个字段提供测试。未完成的适配器应显式失败，而不是猜测 API。

## 决策 7：能力声明先于执行
运行时必须返回 CapabilityManifest。缺少能力声明时，不得推断支持某种干预；策略门在调用后端前校验目标、操作、隔离范围与预算。

## 决策 8：真实后端的高影响操作默认需要审批
真实后端中，标记为需要审批的干预在未获批准时返回 `APPROVAL_REQUIRED`。合成 Mock 操作没有真实副作用，但结果仍然只能标记为 simulated。

## 决策 9：工件内容寻址
本地工件使用 SHA-256 内容寻址，并在读取时校验摘要，避免报告引用与实际数据不一致。

## 0.4.0 补充决策

## 决策 10：只读配置优先
`policy_profile=read_only` 会禁止自动和 API 触发的干预。`auto_intervene=false` 只禁止运行期间自动执行，仍允许在单独授权和预算检查后提交候选干预。

## 决策 11：真实写操作必须同时具备授权引用和操作员审批
真实后端的写操作必须使用 `isolated_test_environment` 范围、提供 `authorization_ref`，并通过独立的 `AGENTGUARD_APPROVAL_TOKEN`。仅把请求参数中的 `approval_required` 设为 false 不能绕过审批。

## 决策 12：主动调查分数只用于排序
调查动作的 information-gain/cost/risk 分数是透明启发式指标，不是校准后的信息论估计。系统输出配对设计，但不宣称计划已经执行。

## 决策 13：经验记忆不自动提升为策略
经验记录必须有版本、来源、验证状态和适用范围。只有通过字段校验、拥有重复与证据引用、并显式开启推荐的 verified 记录，才会出现在自动推荐查询结果中；推荐也不会自动执行。

## 决策 14：监督检测按案例家族切分
线性探针训练接口要求 `case_families`，训练/测试拆分不允许同一案例家族跨集合。探针只消费调用方提供的数值特征，不自动提取模型激活，也不证明因果机制。

## 决策 15：后台取消是协作式的
运行任务在安全编排检查点响应取消；底层同步 API 正在执行时，AgentGuard 不会伪称能够强制终止模型服务调用。被取消的运行保存已收集证据并返回 partial 报告。


## 0.5.0 补充决策

## 决策 16：研究预注册不可原位覆盖
注册表为规范化方案计算 SHA-256；方案变化应新建注册并记录偏离，不能覆盖已有注册记录。该哈希不等同于可信时间戳或第三方公证。

## 决策 17：家族内 episode 不默认视为独立样本
默认 `clustered_paired` 分析先在案例家族内聚合配对差值，再以家族为重采样和符号翻转单位；研究报告明确其估计量与小簇数限制。

## 决策 18：多重比较规则必须可追溯
确认性分析只接受注册的主终点和次终点，按注册方案使用 Holm、Benjamini–Hochberg 或显式不校正；系统不会自动把事后添加终点认定为确认性结果。

## 决策 19：LLM Investigator 无工具权和干预授权权
外部模型只收到经过裁剪的候选 Finding 元数据，返回的 ID 必须属于候选集合。无效响应和 provider 错误回退到确定性调查器；所有干预仍由本地策略闸门决定。
