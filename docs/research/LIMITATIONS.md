# 调查评价研究的限制（D5）

1. **结论范围**：本轮对比的是上层调查**动作选择行为**。基础证据来自单一真实
   观察运行（同 seed 冻结观察），策略间模型/内核行为完全相同——结果不能解释为
   模型能力或检测准确率差异。
2. **聚合指标同质**：在当前只读动作集与预算下，各策略都遍历全部动作，聚合
   指标一致属预期；差异只体现在动作顺序（逐轮记录可见）与降级路径
   （experience/llm 降级率 1.0）。这不构成任何策略优越性结论。
3. **单基础调查 × 2 重复**：无跨场景方差；重复运行只验证确定性/稳定性。
4. **风险识别与防御效果指标为 null**：前者需独立合法真值标注（当前按真值
   隔离决策不可得），后者需真实干预执行器与配对独立评价（DEP-006/007）。
   二者在合同层恒为 null，不以代理指标填充。
5. **LLM 策略未接真实提供商**：本轮全部按合同降级运行；接入后降级率将反映
   提供商可用性，且仍受候选集约束与预算限制。
6. **真实内核限制**：StegoPot 冻结观察按 seed 复用首次结果，多种子真实重复
   在当前内核不可执行；跨种子方差未知。
